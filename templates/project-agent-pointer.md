# Shared agent instructions

Use the universal Winplaybox agent operating contract and the `idea-to-production` skill from:

https://github.com/Winplaybox/emergentagent

Keep this repository's agent instructions limited to project-specific context:
- Purpose and users
- Stack and architecture
- Folder/module map
- Setup, lint, test and build commands
- Environment variable names (never secret values)
- Project-specific constraints and acceptance criteria

Do not duplicate global workflow rules here. Do not make paid, destructive, public, or production-impacting changes without explicit approval.
